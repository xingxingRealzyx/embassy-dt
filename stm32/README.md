# embassy-dt-stm32

STM32 backend for [`embassy-dt`](https://docs.rs/embassy-dt): turns a device tree into
typed [Embassy](https://github.com/embassy-rs/embassy) HAL instances, including
interrupt bindings and DMA wiring.

Configuration is written as `.dts` / `.dtsi` device tree files (or the Rust DSL); the
`device_tree!` macro generates the typed `Board` structure and the `clock_config()`
function for you:

```rust
use embassy_dt::device_tree;

device_tree! {
    name "my-board";
    backend stm32;
    chip "stm32h723zg";
    from "boards/my-board.dts";
}

#[embassy_executor::main]
async fn main(_spawner: Spawner) {
    let p = embassy_stm32::init(clock_config());
    let board = Board::init(p);   // generated by device_tree!
    // board.led0, board.uart0, board.can0, ...
}
```

## Supported chips

- `stm32h723zg` (default) / `stm32h723vg`
- `stm32f411ce`
- `stm32l476rg`
- `stm32g474re` / `stm32g474ve` (requires the `single-bank` feature, enabled by the
  backend feature definition)
- `stm32f103c8` / `stm32f103re`
- `stm32f072rb`

Enable exactly one chip feature; the backend defines them as
`stm32h723zg = ["embassy-stm32/stm32h723zg", ...]`. Use
`default-features = false` on this crate and select your chip explicitly:

```toml
[dependencies]
embassy-dt-stm32 = { path = "../embassy-dt/stm32", default-features = false, features = ["stm32g474ve"] }
```

## Notes

- The `rt`, `time-driver-any` and `exti` features of `embassy-stm32` are enabled by this
  crate. Do not override them away: without `rt`, interrupt vectors (including the time
  driver timer ISR) are not compiled and timers hang.
- Pin alternate functions, DMA channel compatibility and interrupt bindings are checked
  at compile time by the Embassy type system.
- Real-hardware verified: ATK-DMG474 (STM32G474VET6) LED heartbeat. See the repository
  root README for the full status.

Full documentation: [`embassy-dt`](https://docs.rs/embassy-dt). The `examples/` directory
contains 20+ firmware examples rewritten from the official Embassy examples in the
device-tree style.
