# embassy-dt-bme280

BME280 temperature/humidity/pressure driver following the `embassy-dt` device-tree init
convention:

```rust
async fn init(deps..., &NodeDesc) -> Result<Self, DeviceError>
```

Declare the sensor in the device tree; the macro-generated `init_devices()` injects the
I2C bus in dependency order and performs reset / ID check / calibration-parameter read /
integer-compensated temperature and humidity:

```dts
bme280: bme@76 {
    compatible = "bosch,bme280";
    bus = <&i2c0>;
    addr = <0x76>;
    driver = "embassy_dt_bme280::Bme280<...>";
};
```

`no_std`, zero allocation, works over any `embedded-hal-async` I2C implementation,
including the shared-bus proxies generated by `embassy-dt` (`shared;`).

Full documentation: [`embassy-dt`](https://docs.rs/embassy-dt).
